# F1 — טופס יצירת בקשת חופשה

## מצב והיקף

מומש ואומת בצד Angular; אימות משולב ממתין לתיאום. התיעוד נכתב ב-2026-09-09 על סמך הרצות שבוצעו בשיחה זו, ולא בעקבות הרצה חדשה בסבב התיעוד.

שונו רק קובצי leave-requests.component.ts/html/css ונוסף leave-requests.component.spec.ts בתיקיית frontend/src/app/leave-requests. לא שונו Backend, תלויות, Docker או התנהגות כפתור האישור. לאחר השלמת התיעוד, המשתמשת אישרה commit ו-push של F1. מסמכי המעקב ו-DECISIONS עודכנו בנפרד לאחר אישור המשתמשת שסוכן התיעוד סיים לערוך אותם.

## תוצאות הרצה

- `npm.cmd run build` מתוך frontend: עבר; חבילת production נוצרה בהצלחה.
- `npm.cmd test -- --watch=false --browsers=ChromeHeadless`: עבר; TOTAL: 13 SUCCESS, קוד יציאה 0. 12 בדיקות F1 חדשות ובדיקה קיימת של AppComponent. האימות האחרון התחבר ל-Chrome ב-17:37:43 בתאריך 2026-09-09.
- נעשה שימוש ב-Node המקומי 20.20.2 וב-Chrome המותקן. ניסיון ראשון בסביבה מוגבלת נכשל בהפעלת GPU של Chrome לפני הרצת הבדיקות. ניסיון עם ארגומנט port נדחה כארגומנט לא מוכר. ההרצה הסופית השתמשה בפקודה שלעיל ללא הארגומנט, מחוץ להגבלת ההרצה, והצליחה. לא הותקנו רכיבים.
- `git diff --check -- frontend`: עבר. אזהרות המרת LF ל-CRLF אינן כשל בדיקות.

ראיות: פלטי הכלים בשיחת יישום F1 וקוד הבדיקות. לא נשמר יומן הרצה עצמאי לקובץ; אין לטעון שקיים כזה. במקרה של שינוי נוסף בקוד יש להריץ את הבדיקות מחדש.

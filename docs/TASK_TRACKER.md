תיעוד החלטות, היסטוריית Git ודוגמאות AI אמיתיות הם דרישות הגשה שמתעדכנות לאורך העבודה, ולא בונוס לסוף. בדיקת אבטחה ותיקונה הם בונוס לאחר דרישות הליבה. המטלה ממליצה על כשלוש שעות ומעדיפה השלמת משימות לפי סדר על פני התחלה חלקית של כולן.

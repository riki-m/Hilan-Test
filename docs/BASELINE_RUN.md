## כלים מקומיים

בעת ההכנה הותקנו תחת `.local-tools`, המוחרגת מ-Git: Temurin JDK 21.0.12.1+1, Maven 3.9.16 ו-Node.js 20.20.2. ארכיוני הכלים אומתו מול checksums. `scripts/Use-LocalTools.ps1` טוען אותם למסוף; הוא אינו מתקין אותם במחשב חדש.

לא בוטל אימות TLS: Java משתמש באמון Windows ו-Node בקובץ תעודות ציבוריות מקומי מוחרג. הוראות ההרצה הכלליות נשארות ב-README המקורי.

## תקלות Windows — תיעוד היסטורי בלבד

היו קשיי מקום פנוי, WSL/VirtualMachinePlatform ואתחול Docker. בהמשך בוצעו התקנות ותיקון רכיבי Windows; בסבב B1 הורצו בדיקות מול מסד אמיתי. יומני האבחון נשמרו ב-`.local-run` ולא נמחקו.

לשימור מידע על שינויי המחשב: במהלך התיקון בוטל Hibernate באישור המשתמשת, פעולה שמשביתה גם Fast Startup. אפשרות החזרה שתועדה היא `powercfg /hibernate on` בהרשאת מנהל ובהינתן מקום פנוי; זו אינה בקשה לביצוע כעת. סריקת SFC ההיסטורית נעצרה עקב תיקון ממתין; הצלחת Docker אינה הוכחה שסריקת SFC הושלמה. תיקיות תקשורת Docker נשמרו אז בשמות גיבוי, ללא מחיקת נתוני containers/images.
